# Bundling Code for the BPMN Playground

This folder contains the Vite project for the BPMN Playground used on the **Fluxnova Playground** page in the **Get Started** section.

Before running the playground, complete the following steps:

1. Navigate to this folder:

   ```bash
   cd bpmn-playground
   ```

2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Build the project:

   ```bash
   npm run build
   ```

   Wait for the build to complete successfully.

4. Return to the repository root:

   ```bash
   cd ..
   ```

5. Start the Hugo development server:

   ```bash
   hugo server --baseURL="http://localhost"
   ```

For additional setup instructions and project information, see the [Main README](../README.md).
